# Simple HTML Website (NovaCraft)

A clean, modern, and responsive website built with vanilla HTML5, CSS3, and JavaScript.

## 🚀 Features

- **Semantic HTML5:** Clean, accessible, and SEO-friendly document structure.
- **Modern Responsive Design:** Flexbox & Grid layouts optimized for mobile, tablet, and desktop screens.
- **Light & Dark Mode:** Theme switcher with automatic `localStorage` preference memory.
- **Interactive Widgets:** Interactive counter demonstration and mobile menu drawer.
- **Contact Form Validation:** Client-side form submission simulation with user feedback.
- **Zero Dependencies:** Pure vanilla code — no build tools, node modules, or external frameworks required.

## 📂 Project Structure

```
├── index.html        # Main HTML structure and content
├── style.css         # Modern styling, responsive queries, and dark/light mode CSS variables
├── script.js         # Interactive features (theme toggle, counter, mobile menu, contact form)
└── README.md         # Documentation
```

## 🌐 How to View the Website

You can open the website in several simple ways:

### 1. Direct Browser Open (Double Click)
Navigate to your folder (`c:\Users\DELL\Desktop\agentic ai ws`) and double-click `index.html` to open it in Chrome, Edge, Firefox, or Safari.

### 2. Using Python Local Server (Optional)
If you have Python installed, open PowerShell in this directory and run:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

### 3. Using VS Code Live Server Extension (Optional)
Right-click `index.html` in VS Code / Antigravity and select **"Open with Live Server"**.
